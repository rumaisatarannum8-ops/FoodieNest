Restro – Restaurant Landing Page

Overview

Restro is a modern and attractive restaurant landing page built using HTML and CSS. It features a clean navigation bar, a delicious food-themed background, and an animated food image to create an engaging user experience.

Features

- Responsive-style landing page layout
- Navigation menu with icons
- Attractive hero section
- Animated food image using CSS keyframes
- Background overlay for better text visibility
- Book Table button

Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

Description

The main purpose of this project is to create a visually appealing restaurant homepage that introduces the restaurant and highlights its food services. CSS animations and styling make the design more interactive and attractive.
